# ATPG for 8-bit FIFO using Cadence Modus

This project demonstrates the insertion of ATPG (Automatic Test Pattern Generation) for an 8-bit FIFO design using Cadence Genus and Cadence Modus. It covers DFT setup, scan insertion, ATPG pattern generation, and fault simulation.

---

## Overview

The objective is to generate ATPG patterns for the FIFO design after performing scan insertion and DFT rule checks. The workflow integrates synthesis (Genus) and ATPG (Modus) through an automated TCL-based flow.

---

## Requirements

* Cadence Genus
* Cadence Modus
* SAED 90nm library files
* RTL design files for the FIFO

---

## Flow Steps

1. Prepare the RTL design files and required technology libraries.
2. Run the automation TCL script to:

   * Read library and RTL files
   * Elaborate the design
   * Configure DFT settings (scan style, test clocks, test modes)
   * Check DFT rules
   * Insert scan chains
   * Perform logic synthesis and optimization
   * Generate scan netlist
   * Export ATPG-related files for Modus
3. Import generated files into Cadence Modus for ATPG processing.
4. Generate ATPG patterns and review the fault coverage reports.
5. Perform fault simulation using the generated patterns.
6. Observe waveform output and finalize test results.

---

## Notes

* Muxed flip-flops are used as scan cells in this design.
* All scan chain connections and DFT rule checks should be verified before ATPG generation.

---

## Output Files

* `scan_netlist.v` – Netlist with scan inserted
* `scan_chain_file.txt` – Scan chain information
* `scan_setup_file.txt` – DFT and scan configuration details
* ATPG pattern files generated by Modus
* Fault coverage and diagnostic reports
